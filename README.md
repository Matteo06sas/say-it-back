# Say It Back

A short interactive English course for B1–B2 learners. The public site includes eight lessons with dialogues, narrated passages, comprehension questions, and open response prompts.

## Publish with GitHub Pages

1. Create a **public** repository named `say-it-back` under `Matteo06sas`.
2. In the repository settings, open **Pages** and set the source to **GitHub Actions**.
3. Add the files from this package to the repository's `main` branch.
4. The included workflow publishes the site on every push to `main`.

Expected address: https://matteo06sas.github.io/say-it-back/

This is a static site; it needs no build step or backend. Progress and responses are saved in each learner's browser. Voiceover uses browser speech synthesis where available. The answer feedback is guided and is not an AI grammar correction service.
